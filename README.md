✨ Visão Geral
A plataforma foi concebida para ser uma ferramenta central para a ONG EVRN (Eder Vitor Reis Nogueira), permitindo gerenciar atividades, divulgar projetos, captar recursos e engajar voluntários. A aplicação foi desenvolvida com uma arquitetura de Single Page Application (SPA), onde o conteúdo é carregado dinamicamente para proporcionar uma experiência de usuário fluida e rápida.

🚀 Funcionalidades Principais
Arquitetura SPA (Single Page Application): Navegação instantânea entre as páginas (Início, Projetos, Cadastro) sem a necessidade de recarregar a página inteira.

Design Responsivo (Mobile-First): A interface se adapta perfeitamente a diferentes tamanhos de tela, desde smartphones e tablets até desktops, utilizando CSS Grid e Flexbox.

Sistema de Design Consistente: O projeto utiliza variáveis CSS para manter a consistência em cores, tipografia e espaçamentos, facilitando a manutenção e a escalabilidade.

Componentes de UI Modernos:

Cards de Projeto: Exibição clara e organizada dos projetos da ONG.

Botões Interativos: Estados visuais (hover, focus, active) para melhor feedback ao usuário.

Navegação Sofisticada: Menu principal com submenu dropdown e um menu "hambúrguer" funcional para dispositivos móveis.

Formulário de Cadastro Avançado:

Validação em Tempo Real: O JavaScript valida os dados inseridos pelo usuário (nome, e-mail, CPF) antes do envio.

Feedback Visual Imediato: O usuário recebe mensagens claras sobre campos preenchidos incorretamente, melhorando a usabilidade.

Máscaras de Input: Formatação automática para campos como CPF, telefone e CEP.

Estrutura Semântica e Acessível: O código HTML5 utiliza tags semânticas para otimizar o SEO e garantir a acessibilidade para leitores de tela.
